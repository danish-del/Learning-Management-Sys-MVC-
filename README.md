🎓 Learning Management System (LMS)
A web-based Learning Management System developed using ASP.NET Core MVC (.NET 8). This application provides a platform for managing students, courses, enrollments, assignments, submissions, and learning activities through a centralized dashboard.

🚀 Features
👨‍🎓 Student Management

View and manage student information

Student dashboard

📚 Course Management

Create and manage courses

View available courses

📝 Assignment Management

Create and manage assignments

Assign assignments to courses

📤 Assignment Submission

Students can submit assignments

Manage and review submissions

📋 Course Enrollment

Students can enroll in courses

View enrolled courses

📊 Dashboard

Centralized dashboard

Overview of courses, students, enrollments, and assignments

🔐 Authentication & Authorization

Secure user authentication

Role-based access where applicable
